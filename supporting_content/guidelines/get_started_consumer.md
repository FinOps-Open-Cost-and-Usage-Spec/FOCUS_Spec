Welcome to the FOCUS Consumer Get Started guide. You are in the right place if you're working with FOCUS data and need practical guidance to get started.

# Scope and purpose

This guide provides practical, foundational guidance for anyone _consuming_ FOCUS data.
It doesn't replace the FOCUS specification; it provides an overarching resource to flatten the learning curve.
It helps you identify the context behind the data so you can interpret it correctly.
Making sense of the data can be tricky when you have both enterprise pricing agreements and savings plans, or seasonal and event-based discounts.
This guide provides pointers to help you disentangle it.
