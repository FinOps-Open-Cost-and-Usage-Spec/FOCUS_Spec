# Contract Commitment Currency

Contract Commitment Currency is an identifier that represents the currency of a [*contract commitment*](#glossary:contract-commitment).

The ContractCommitmentCurrency column adheres to the following requirements:

* ContractCommitmentCurrency MUST be present in a [*FOCUS dataset*](#glossary:FOCUS-dataset).
* ContractCommitmentCurrency MUST be of type String.
* ContractCommitmentCurrency MUST conform to [StringHandling](#stringhandling) requirements.
* ContractCommitmentCurrency MUST conform to [CurrencyFormat](#currencyformat) requirements.
* ContractCommitmentCurrency MUST NOT be null when [ContractCommitmentCategory](#contractcommitmentcategory) is "Spend".
* ContractCommitmentCurrency SHOULD match the currency used in the invoice generated by the invoice issuer.
* ContractCommitmentCurrency MUST be expressed in [*national currency*](#glossary:national-currency) (e.g., USD, EUR).

## Column ID

ContractCommitmentCurrency

## Display Name

Contract Commitment Currency

## Description

Represents the currency of a *contract commitment*.
