# Billing Currency

[Billing Currency](#term) is an identifier that represents the currency that a [charge](#term) for [resources](#term) or [services](#term) was billed in. [Billing Currency](#col) is commonly used in scenarios where costs need to be grouped or aggregated.

## Requirements

[BillingCurrency](#col) MUST adhere to the following requirements:

* [BillingCurrency](#col) MUST be of type String.
* [BillingCurrency](#col) MUST conform to [StringHandling](#attr) requirements.
* [BillingCurrency](#col) MUST conform to [CurrencyFormat](#attr) requirements.
* [BillingCurrency](#col) MUST NOT be null.
* [BillingCurrency](#col) MUST match the currency used in the invoice generated by the [invoice issuer](#term).
* [BillingCurrency](#col) MUST be expressed in [national currency](#term) (e.g., USD, EUR).

## Column ID

BillingCurrency

## Display Name

Billing Currency

## Description

Represents the currency that a [charge](#term) was billed in.
