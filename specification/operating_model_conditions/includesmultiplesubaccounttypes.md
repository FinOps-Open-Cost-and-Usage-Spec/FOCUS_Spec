# Includes Multiple Sub Account Types

The [Includes Multiple Sub Account Types](#omc) operating model condition represents a verifiable state indicating whether the [operating model](#term) includes multiple [Sub Account Types](#col:SubAccountType).

## Requirements

[IncludesMultipleSubAccountTypes](#omc) MUST adhere to the following requirements:

* [IncludesMultipleSubAccountTypes](#omc) MUST evaluate to true when the [operating model](#term) includes multiple SubAccountTypes.
* [IncludesMultipleSubAccountTypes](#omc) MUST evaluate to false when the [operating model](#term) does not include multiple SubAccountTypes.

## Operating Model Condition ID

IncludesMultipleSubAccountTypes

## Display Name

Includes Multiple Sub Account Types

## Description

A verifiable state indicating whether the [operating model](#term) includes multiple Sub Account Types.

## Version Introduced

1.5
