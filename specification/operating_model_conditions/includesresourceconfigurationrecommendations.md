# Includes Resource Configuration Recommendations

The Includes Resource Configuration Recommendations condition represents a verifiable state indicating whether the [*operating model*](#glossary:operating-model) includes recommendations to change the configuration of a [*resource*](#glossary:resource).

## Requirements

IncludesResourceConfigurationRecommendations MUST adhere to the following requirements:

* IncludesResourceConfigurationRecommendations MUST evaluate to true when the *operating model* includes recommendations to change the configuration of a *resource*.
* IncludesResourceConfigurationRecommendations MUST evaluate to false when the *operating model* does not include recommendations to change the configuration of a *resource*.

## Condition ID

IncludesResourceConfigurationRecommendations

## Display Name

Includes Resource Configuration Recommendations

## Description

A verifiable state indicating whether the *operating model* includes recommendations to change the configuration of a resource.

## Version Introduced

1.5
