# Includes Regions

The [Includes Regions](#omc) operating model condition represents a verifiable state indicating whether the [operating model](#term) includes deploying [resources](#term) or [services](#term) within a region.

## Requirements

[IncludesRegions](#omc) MUST adhere to the following requirements:

* [IncludesRegions](#omc) MUST evaluate to true when the [operating model](#term) includes deploying [resources](#term) or [services](#term) within a region.
* [IncludesRegions](#omc) MUST evaluate to false when the [operating model](#term) does not include deploying [resources](#term) or [services](#term) within a region.

## Operating Model Condition ID

IncludesRegions

## Display Name

Includes Regions

## Description

A verifiable state indicating whether the [operating model](#term) includes deploying [resources](#term) or [services](#term) within a region.

## Version Introduced

1.5
