# Includes Quantity Tier Pricing

The Includes Quantity Tier Pricing operating model condition represents a verifiable state indicating whether the [*operating model*](#glossary:operating-model) includes quantity-based pricing tiers.

> **Preview:** Includes Quantity Tier Pricing exists for the SKU Price dataset, which is a [*preview*](#glossary:preview) in this version of FOCUS. While that dataset is a preview, Includes Quantity Tier Pricing may change in the next version without a deprecation notice.

## Requirements

IncludesQuantityTierPricing MUST adhere to the following requirements:

* IncludesQuantityTierPricing MUST evaluate to true when the *operating model* includes quantity-based pricing tiers.
* IncludesQuantityTierPricing MUST evaluate to false when the *operating model* does not include quantity-based pricing tiers.

## Operating Model Condition ID

IncludesQuantityTierPricing

## Display Name

Includes Quantity Tier Pricing

## Description

A verifiable state indicating whether the *operating model* includes quantity-based pricing tiers.
