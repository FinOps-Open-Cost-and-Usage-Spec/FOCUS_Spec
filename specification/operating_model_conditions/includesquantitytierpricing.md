# Includes Quantity Tier Pricing

The [Includes Quantity Tier Pricing](#omc) operating model condition represents a verifiable state indicating whether the [operating model](#term) includes quantity-based pricing tiers.

> **Preview:** [Includes Quantity Tier Pricing](#omc) exists for the SKU Price dataset, which is a preview in this version of FOCUS. While that dataset is a preview, [Includes Quantity Tier Pricing](#omc) may change in the next version without a deprecation notice.

## Requirements

[IncludesQuantityTierPricing](#omc) MUST adhere to the following requirements:

* [IncludesQuantityTierPricing](#omc) MUST evaluate to true when the [operating model](#term) includes quantity-based pricing tiers.
* [IncludesQuantityTierPricing](#omc) MUST evaluate to false when the [operating model](#term) does not include quantity-based pricing tiers.

## Operating Model Condition ID

IncludesQuantityTierPricing

## Display Name

Includes Quantity Tier Pricing

## Description

A verifiable state indicating whether the [operating model](#term) includes quantity-based pricing tiers.

## Version Introduced

Preview: 1.5
