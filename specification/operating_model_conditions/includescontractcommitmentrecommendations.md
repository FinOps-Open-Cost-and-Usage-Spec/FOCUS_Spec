# Includes Contract Commitment Recommendations

The Includes Contract Commitment Recommendations condition represents a verifiable state indicating whether the [*operating model*](#glossary:operating-model) includes recommendations to purchase [*contract commitments*](#glossary:contract-commitment).

## Requirements

IncludesContractCommitmentRecommendations MUST adhere to the following requirements:

* IncludesContractCommitmentRecommendations MUST evaluate to true when the *operating model* includes recommendations to purchase *contract commitments*.
* IncludesContractCommitmentRecommendations MUST evaluate to false when the *operating model* does not include recommendations to purchase *contract commitments*.

## Condition ID

IncludesContractCommitmentRecommendations

## Display Name

Includes Contract Commitment Recommendations

## Description

A verifiable state indicating whether the *operating model* includes recommendations to purchase contract commitments.

## Version Introduced

1.5
