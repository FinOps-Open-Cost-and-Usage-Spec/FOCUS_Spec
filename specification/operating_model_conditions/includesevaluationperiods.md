# Includes Evaluation Periods

The Includes Evaluation Periods operating model condition represents a verifiable state indicating whether the [*operating model*](#glossary:operating-model) includes recommendations derived from a period of evaluation.

## Requirements

IncludesEvaluationPeriods MUST adhere to the following requirements:

* IncludesEvaluationPeriods MUST evaluate to true when the *operating model* includes recommendations derived from a period of evaluation.
* IncludesEvaluationPeriods MUST evaluate to false when the *operating model* does not include recommendations derived from a period of evaluation.

## Operating Model Condition ID

IncludesEvaluationPeriods

## Display Name

Includes Evaluation Periods

## Description

A verifiable state indicating whether the *operating model* includes recommendations derived from a period of evaluation.

## Version Introduced

1.5
