# Includes Negotiated Pricing

The Includes Negotiated Pricing operating model condition represents a verifiable state indicating whether the [*operating model*](#glossary:operating-model) includes negotiated pricing concepts.

## Requirements

IncludesNegotiatedPricing MUST adhere to the following requirements:

* IncludesNegotiatedPricing MUST evaluate to true when the *operating model* includes negotiated pricing concepts.
* IncludesNegotiatedPricing MUST evaluate to false when the *operating model* does not include negotiated pricing concepts.

## Operating Model Condition ID

IncludesNegotiatedPricing

## Display Name

Includes Negotiated Pricing

## Description

A verifiable state indicating whether the *operating model* includes negotiated pricing concepts.

## Version Introduced

1.5
