# Includes Usage Measurement

The [Includes Usage Measurement](#omc) operating model condition represents a verifiable state indicating whether the [operating model](#term) includes the measurement of [resource](#term) or [service](#term) usage.

## Requirements

[IncludesUsageMeasurement](#omc) MUST adhere to the following requirements:

* [IncludesUsageMeasurement](#omc) MUST evaluate to true when the [operating model](#term) includes the measurement of [resource](#term) or [service](#term) usage.
* [IncludesUsageMeasurement](#omc) MUST evaluate to false when the [operating model](#term) does not include the measurement of [resource](#term) or [service](#term) usage.

## Operating Model Condition ID

IncludesUsageMeasurement

## Display Name

Includes Usage Measurement

## Description

A verifiable state indicating whether the [operating model](#term) includes the measurement of [resource](#term) or [service](#term) usage.

## Version Introduced

1.5
