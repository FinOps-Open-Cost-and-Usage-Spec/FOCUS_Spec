# Includes Purchases

The [Includes Purchases](#omc) operating model condition represents a verifiable state indicating whether the [operating model](#term) includes purchases.

> **Preview:** [Includes Purchases](#omc) exists for the SKU Price dataset, which is a preview in this version of FOCUS. While that dataset is a preview, [Includes Purchases](#omc) may change in the next version without a deprecation notice.

## Requirements

[IncludesPurchases](#omc) MUST adhere to the following requirements:

* [IncludesPurchases](#omc) MUST evaluate to true when the [operating model](#term) includes purchases.
* [IncludesPurchases](#omc) MUST evaluate to false when the [operating model](#term) does not include purchases.

## Operating Model Condition ID

IncludesPurchases

## Display Name

Includes Purchases

## Description

A verifiable state indicating whether the [operating model](#term) includes purchases.

## Version Introduced

Preview: 1.5
