# Includes Purchases

The Includes Purchases operating model condition represents a verifiable state indicating whether the [*operating model*](#glossary:operating-model) includes purchases.

> **Preview:** Includes Purchases exists for the SKU Price dataset, which is a preview in this version of FOCUS. While that dataset is a preview, Includes Purchases may change in the next version without a deprecation notice.

## Requirements

IncludesPurchases MUST adhere to the following requirements:

* IncludesPurchases MUST evaluate to true when the *operating model* includes purchases.
* IncludesPurchases MUST evaluate to false when the *operating model* does not include purchases.

## Operating Model Condition ID

IncludesPurchases

## Display Name

Includes Purchases

## Description

A verifiable state indicating whether the *operating model* includes purchases.
