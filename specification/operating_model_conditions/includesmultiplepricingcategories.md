# Includes Multiple Pricing Categories

The [Includes Multiple Pricing Categories](#omc) operating model condition represents a verifiable state indicating whether the [operating model](#term) includes multiple pricing categories.

## Requirements

[IncludesMultiplePricingCategories](#omc) MUST adhere to the following requirements:

* [IncludesMultiplePricingCategories](#omc) MUST evaluate to true when the [operating model](#term) includes multiple pricing categories.
* [IncludesMultiplePricingCategories](#omc) MUST evaluate to false when the [operating model](#term) does not include multiple pricing categories.

## Operating Model Condition ID

IncludesMultiplePricingCategories

## Display Name

Includes Multiple Pricing Categories

## Description

A verifiable state indicating whether the [operating model](#term) includes multiple pricing categories.

## Version Introduced

1.5
