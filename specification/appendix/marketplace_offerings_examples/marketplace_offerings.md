# Marketplace Offering Scenarios

The scenarios described below illustrate how a FOCUS-compliant dataset should look for Marketplace offerings. Each scenario includes two datasets: one containing purchase records generated by the CSP, and one containing the corresponding usage records generated by the Marketplace seller. The examples show how the content of these datasets may vary depending on where the offering is hosted and the level of visibility into the underlying Host Provider.

## Scenario 1: Marketplace Offerings on Third-Party Infrastructure (w/ Host Provider Visibility)

This scenario covers Marketplace offerings hosted outside of your CSP infrastructure, where the underlying Host Provider is visible. The scenario includes two datasets: the dataset generated by the CSP contains purchase records, while the dataset generated by the Marketplace seller contains usage records for the offering.
