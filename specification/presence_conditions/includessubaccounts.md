# Includes Sub Accounts

The Includes Sub Accounts presence condition represents a verifiable state where the [source operating model](#glossary:source-operating-model) includes a sub account construct.

## Requirements

IncludesSubAccounts MUST adhere to the following requirements:

* IncludesSubAccounts MUST evaluate to true when the source operating model supports the use of sub accounts under a main billing account.
* IncludesSubAccounts MUST evaluate to false when the source operating model does not support a sub account construct.

## Presence Condition ID

IncludesSubAccounts

## Display Name

Includes Sub Accounts

## Description

A verifiable state indicating whether the source operating model includes a sub account construct.

## Version Introduced

1.5
