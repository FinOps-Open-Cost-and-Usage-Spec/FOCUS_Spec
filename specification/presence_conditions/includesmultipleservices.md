# Includes Multiple Services

The Includes Multiple Services presence condition represents a verifiable state where the source operating model source operating model includes multiple services.

## Requirements

IncludesMultipleServices MUST adhere to the following requirements:

* IncludesMultipleServices MUST evaluate to true when the source operating model provides multiple distinct services.
* IncludesMultipleServices MUST evaluate to false when the source operating model provides only a single service.

## Presence Condition ID

IncludesMultipleServices

## Display Name

Includes Multiple Services

## Description

A verifiable state indicating whether the source operating model includes multiple services.

## Version Introduced

1.5
