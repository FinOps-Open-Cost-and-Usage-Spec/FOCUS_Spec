# Includes Account Naming

The Includes Account Naming presence condition represents a verifiable state where the [source operating model](#glossary:source-operating-model) includes assigning a display name for the billing account.

## Requirements

IncludesAccountNaming MUST adhere to the following requirements:

* IncludesAccountNaming MUST evaluate to true when the source operating model allows assigning a display name for the billing account.
* IncludesAccountNaming MUST evaluate to false when the source operating model does not allow assigning a display name for the billing account.

## Presence Condition ID

IncludesAccountNaming

## Display Name

Includes Account Naming

## Description

A verifiable state indicating whether the source operating model includes assigning a display name for the billing account.

## Version Introduced

1.5
