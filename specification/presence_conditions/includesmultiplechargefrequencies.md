# Includes Multiple Charge Frequencies

The Includes Multiple Charge Frequencies presence condition represents a verifiable state where the source operating model source operating model includes multiple charge frequencies.

## Requirements

IncludesMultipleChargeFrequencies MUST adhere to the following requirements:

* IncludesMultipleChargeFrequencies MUST evaluate to true when the source operating model supports multiple frequencies for charges (e.g., One-Time, Recurring, Usage-Based).
* IncludesMultipleChargeFrequencies MUST evaluate to false when the source operating model supports only a single charge frequency.

## Presence Condition ID

IncludesMultipleChargeFrequencies

## Display Name

Includes Multiple Charge Frequencies

## Description

A verifiable state indicating whether the source operating model includes multiple charge frequencies.

## Version Introduced

1.5
