# Includes Payable Invoices

The Includes Payable Invoices presence condition represents a verifiable state where the source operating model source operating model includes payable invoices.

## Requirements

IncludesPayableInvoices MUST adhere to the following requirements:

* IncludesPayableInvoices MUST evaluate to true when the source operating model generates formal payable invoices.
* IncludesPayableInvoices MUST evaluate to false when the source operating model does not generate formal payable invoices.

## Presence Condition ID

IncludesPayableInvoices

## Display Name

Includes Payable Invoices

## Description

A verifiable state indicating whether the source operating model includes payable invoices.

## Version Introduced

1.5
