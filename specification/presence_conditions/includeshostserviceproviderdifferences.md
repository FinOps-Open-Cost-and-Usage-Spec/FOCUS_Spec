# Includes Host-Service Provider Differences

The Includes Host-Service Provider Differences presence condition represents a verifiable state where the source operating model source operating model includes public delineation between host and service provider.

## Requirements

IncludesHostServiceProviderDifferences MUST adhere to the following requirements:

* IncludesHostServiceProviderDifferences MUST evaluate to true when the source operating model explicitly delineates between the host provider and the service provider.
* IncludesHostServiceProviderDifferences MUST evaluate to false when the source operating model does not distinguish between host and service provider.

## Presence Condition ID

IncludesHostServiceProviderDifferences

## Display Name

Includes Host-Service Provider Differences

## Description

A verifiable state indicating whether the source operating model includes public delineation between host and service provider.

## Version Introduced

1.5
