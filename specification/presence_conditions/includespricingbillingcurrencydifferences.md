# Includes Pricing-Billing Currency Differences

The Includes Pricing-Billing Currency Differences presence condition represents a verifiable state where the source operating model source operating model includes pricing and billing in different currencies.

## Requirements

IncludesPricingBillingCurrencyDifferences MUST adhere to the following requirements:

* IncludesPricingBillingCurrencyDifferences MUST evaluate to true when the source operating model supports pricing in one currency and billing in another.
* IncludesPricingBillingCurrencyDifferences MUST evaluate to false when the source operating model strictly uses the same currency for pricing and billing.

## Presence Condition ID

IncludesPricingBillingCurrencyDifferences

## Display Name

Includes Pricing-Billing Currency Differences

## Description

A verifiable state indicating whether the source operating model includes pricing and billing in different currencies.

1.5
