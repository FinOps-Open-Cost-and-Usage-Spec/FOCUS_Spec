# Includes Provisioned Resources

The Includes Provisioned Resources presence condition represents a verifiable state where the [source operating model](#glossary:source-operating-model) includes provisioned resources.

## Requirements

IncludesProvisionedResources MUST adhere to the following requirements:

* IncludesProvisionedResources MUST evaluate to true when the source operating model identifies and tracks individual provisioned resources.
* IncludesProvisionedResources MUST evaluate to false when the source operating model does not track individual provisioned resources.

## Presence Condition ID

IncludesProvisionedResources

## Display Name

Includes Provisioned Resources

## Description

A verifiable state indicating whether the source operating model includes provisioned resources.

## Version Introduced

1.5
