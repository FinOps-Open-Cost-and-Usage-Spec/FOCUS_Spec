# Defines Multiple Sub Account Types

The Defines Multiple Sub Account Types presence condition represents a verifiable state where the [source operating model](#glossary:source-operating-model) defines more than one possible SubAccountType value.

## Requirements

DefinesMultipleSubAccountTypes MUST adhere to the following requirements:

* DefinesMultipleSubAccountTypes MUST evaluate to true when the source operating model defines more than one possible SubAccountType value.
* DefinesMultipleSubAccountTypes MUST evaluate to false when the source operating model defines only a single SubAccountType value.

## Presence Condition ID

DefinesMultipleSubAccountTypes

## Display Name

Defines Multiple Sub Account Types

## Description

A verifiable state indicating whether the source operating model defines more than one possible SubAccountType value.

## Version Introduced

1.5
