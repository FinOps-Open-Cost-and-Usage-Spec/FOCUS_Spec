# Includes Commitment Discounts

The Includes Commitment Discounts presence condition represents a verifiable state where the source operating model source operating model includes commitment discounts.

## Requirements

IncludesCommitmentDiscounts MUST adhere to the following requirements:

* IncludesCommitmentDiscounts MUST evaluate to true when the source operating model includes one or more programs where a customer commits to a level of usage or spend in exchange for reduced rates.
* IncludesCommitmentDiscounts MUST evaluate to false when the source operating model does not include any commitment-based pricing or discount programs.

## Presence Condition ID

IncludesCommitmentDiscounts

## Display Name

Includes Commitment Discounts

## Description

A verifiable state indicating whether the source operating model includes commitment discounts.

## Version Introduced

1.5
