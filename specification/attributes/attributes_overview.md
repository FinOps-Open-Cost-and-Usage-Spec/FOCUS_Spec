# Attributes

Attributes define reusable sets of requirements that apply either across a [*FOCUS dataset*](#glossary:FOCUS-dataset) or other specification entity (column, object, etc.). An attribute is associated with a specification entity in their respective Requirements sections to indicate that the specification entity conforms to the attribute.  Requirements on data content can include naming conventions, data types, formatting standardizations, etc. Attributes may introduce high-level requirements for data granularity, recency, frequency, etc. Within an attribute, each requirement applies to the specification entity being constrained; the attribute serves as the grouping mechanism. Requirements defined in attributes are necessary for servicing [FinOps capabilities][FODOFC] accurately using a standard set of instructions regardless of the origin of the data.
