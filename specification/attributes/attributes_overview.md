# Attributes

Attributes define reusable sets of requirements that apply either across a [*FOCUS dataset*](#glossary:FOCUS-dataset) or an individual column level. An attribute is associated with a dataset or column in their respective Requirements sections to indicate that the specification entity (dataset, column, etc) conforms to the attribute.  Requirements on data content can include naming conventions, data types, formatting standardizations, etc. Attributes may introduce high-level requirements for data granularity, recency, frequency, etc. Within an attribute, each requirement applies to the relevant dataset, column, or data structure being constrained; the attribute serves as the grouping mechanism. Requirements defined in attributes are necessary for servicing [FinOps capabilities][FODOFC] accurately using a standard set of instructions regardless of the origin of the data.
