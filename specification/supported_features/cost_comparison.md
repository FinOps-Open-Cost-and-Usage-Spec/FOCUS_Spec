# Cost Comparison

## Description

FOCUS supports comparing cost columns to identify savings from [*negotiated discounts*](#glossary:negotiated-discount), the impact of [*commitment discount*](#glossary:commitment-discount) amortization, and differences between [*cash-based*](#glossary:cash-based-accounting) and [*accrual-based*](#glossary:accrual-based-accounting) cost perspectives.

[Billed Cost](#datamodel.costandusage.billedcost) represents the *cash-based* view: amounts invoiced by the [Invoice Issuer Name](#datamodel.costandusage.invoiceissuername) in a given [*billing period*](#glossary:billing-period). [Effective Cost](#datamodel.costandusage.effectivecost) represents the *accrual-based* view: costs recognized when [*resources*](#glossary:resource) are consumed, [*services*](#glossary:service) are used, or [*contract commitments*](#glossary:contract-commitment) are recognized. [List Cost](#datamodel.costandusage.listcost) provides the pre-discount baseline. [Contracted Cost](#datamodel.costandusage.contractedcost) reflects pricing after *negotiated discounts*.

Comparing List Cost against Contracted Cost quantifies *negotiated discount* savings; comparing Contracted Cost against Effective Cost isolates *commitment discount* savings; comparing Effective Cost against List Cost shows total combined savings. Billed Cost and Effective Cost diverge when billing timing differs from consumption, such as with *commitment discounts* or prepaid purchases.

When comparing costs across marketplace boundaries, [*practitioners*](#glossary:practitioner) should be aware that Billed Cost is zero for [*charges*](#glossary:charge) generated by entities not responsible for invoicing, so Billed Cost and Effective Cost sums may not align within a single dataset when [*covering charges*](#glossary:covering-charge) and [*covered charges*](#glossary:covered-charge) span multiple [*invoice issuers*](#glossary:invoice-issuer). This is expected and does not indicate a data quality issue. See the [Marketplace Purchases](#supportedfeatures.marketplacepurchases) supported feature, [Examples: Commitment Discount Flexibility](#appendix.examples:commitmentdiscountflexibility), and [Examples: SaaS](#appendix.examples:saas) for additional context.

## Example SQL Queries

### Discount Effectiveness by Service

```sql
WITH AggregatedData AS (
  SELECT
    ServiceProviderName,
    BillingAccountId,
    BillingAccountName,
    BillingCurrency,
    ServiceName,
    SUM(EffectiveCost) AS TotalEffectiveCost,
    SUM(BilledCost) AS TotalBilledCost,
    SUM(CASE
          WHEN ChargeCategory = 'Usage' AND BilledCost = 0 AND EffectiveCost != 0
          THEN 0
          ELSE ContractedCost
        END) AS TotalContractedCost,
    SUM(CASE
          WHEN ChargeCategory = 'Usage' AND BilledCost = 0 AND EffectiveCost != 0
          THEN 0
          ELSE ListCost
        END) AS TotalListCost
  FROM CostAndUsage
  WHERE BillingPeriodStart >= ?
    AND BillingPeriodEnd < ?
    AND ChargeClass IS NULL
  GROUP BY
    ServiceProviderName,
    BillingAccountId,
    BillingAccountName,
    BillingCurrency,
    ServiceName
)
SELECT ServiceProviderName,
    BillingAccountId,
    BillingAccountName,
    BillingCurrency,
    ServiceName,
    TotalEffectiveCost,
    TotalBilledCost,
    TotalListCost,
    (1 - TotalContractedCost / NULLIF(TotalListCost, 0)) * 100 AS ContractedDiscount,
    (1 - TotalEffectiveCost / NULLIF(TotalListCost, 0)) * 100 AS EffectiveDiscount
FROM AggregatedData
```

### Cash vs. Accrual Comparison by Billing Period

```sql
SELECT
  ServiceProviderName,
  InvoiceIssuerName,
  BillingPeriodStart,
  BillingPeriodEnd,
  SUM(BilledCost) AS TotalBilledCost,
  SUM(EffectiveCost) AS TotalEffectiveCost,
  SUM(EffectiveCost) - SUM(BilledCost) AS CostBasisDifference
FROM CostAndUsage
WHERE BillingPeriodStart >= ? AND BillingPeriodEnd < ?
GROUP BY
  ServiceProviderName,
  InvoiceIssuerName,
  BillingPeriodStart,
  BillingPeriodEnd
HAVING ABS(SUM(EffectiveCost) - SUM(BilledCost)) > 0.01
```

### Commitment Discount Savings for a Charge Period Range

For each *commitment discount* within a [*charge period*](#glossary:chargeperiod) range, compares the Contracted Cost of the usage it covered with its total Effective Cost, including the unused portion (i.e., where [Commitment Discount Status](#datamodel.costandusage.commitmentdiscountstatus) is "Unused"). The difference is the net savings attributable to the *commitment discount*, and a negative value means the unused portion cost more than the *commitment discount* saved on covered usage.

```sql
SELECT
  ServiceProviderName,
  BillingCurrency,
  CommitmentDiscountId,
  MIN(ChargePeriodStart) AS ChargePeriodStart,
  MAX(ChargePeriodEnd) AS ChargePeriodEnd,
  SUM(CASE WHEN CommitmentDiscountStatus = 'Used' THEN ContractedCost ELSE 0 END) AS TotalContractedCost,
  SUM(EffectiveCost) AS TotalEffectiveCost,
  SUM(CASE WHEN CommitmentDiscountStatus = 'Used' THEN ContractedCost ELSE 0 END) - SUM(EffectiveCost) AS CommitmentDiscountSavings
FROM focus_data_table
WHERE ChargePeriodStart >= ? AND ChargePeriodEnd < ?
  AND ChargeCategory = 'Usage'
  AND CommitmentDiscountId IS NOT NULL
GROUP BY
  ServiceProviderName,
  BillingCurrency,
  CommitmentDiscountId
```

### Billing Period vs. Charge Period Comparison

A *billing period* identifies when a *charge* is invoiced, while a *charge period* identifies when the *charge* was incurred, so filtering the same data by each can return different totals. This query separates the *charges* in each *billing period* into those whose *charge period* falls within the *billing period* and those whose *charge period* extends outside it (e.g., purchases that cover a longer term).

```sql
SELECT
  ServiceProviderName,
  BillingCurrency,
  BillingPeriodStart,
  BillingPeriodEnd,
  CASE
    WHEN ChargePeriodStart >= BillingPeriodStart AND ChargePeriodEnd <= BillingPeriodEnd
    THEN 'Within Billing Period'
    ELSE 'Outside Billing Period'
  END AS ChargePeriodAlignment,
  MIN(ChargePeriodStart) AS EarliestChargePeriodStart,
  MAX(ChargePeriodEnd) AS LatestChargePeriodEnd,
  SUM(BilledCost) AS TotalBilledCost,
  SUM(EffectiveCost) AS TotalEffectiveCost
FROM focus_data_table
WHERE BillingPeriodStart >= ? AND BillingPeriodEnd < ?
GROUP BY
  ServiceProviderName,
  BillingCurrency,
  BillingPeriodStart,
  BillingPeriodEnd,
  CASE
    WHEN ChargePeriodStart >= BillingPeriodStart AND ChargePeriodEnd <= BillingPeriodEnd
    THEN 'Within Billing Period'
    ELSE 'Outside Billing Period'
  END
```
