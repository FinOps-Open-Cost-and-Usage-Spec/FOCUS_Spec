# Dataset Metadata

## Description

FOCUS supports the ability for data generators to provide metadata about the dataset instances that they provide. This includes information such as the name of the dataset instance, the FOCUS dataset that it aligns with, and an identifier for each dataset instance. This metadata can be used by consumers to understand the context of the data they are receiving, and to ensure that they are working with the correct dataset instance.

## Applicable Metadata

* Daataset
    * Dataset Instance ID
    * Dataset Instance Name
    * FOCUS Dataset ID

## Introduced (Version)

1.3
