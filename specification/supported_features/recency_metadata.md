# Recency Metadata

## Description

FOCUS supports the ability for data generators to provide metadata indicating 1) what portion of a [FOCUS dataset artifact](#term:dataset-artifact) is complete (either in total, or per time sector), and 2) how recently it has been updated. This metadata allows practitioners to understand whether a given subset of FOCUS data is subject to further change, which informs when and whether they can perform various FinOps functions such as chargeback.

## Applicable Metadata

* [Recency](#meta)
  * [Dataset Instance Complete](#meta)
  * [Dataset Instance Last Updated](#meta)
  * [Dataset Instance ID](#meta:Recency.DatasetInstanceId)
  * [Recency Last Updated](#meta)
  * [Time Sectors](#meta)
    * [Time Sector Start](#meta)
    * [Time Sector End](#meta)
    * [Time Sector Complete](#meta)
    * [Time Sector Last Updated](#meta)
