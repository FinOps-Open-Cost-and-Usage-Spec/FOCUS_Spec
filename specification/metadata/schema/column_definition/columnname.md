# Column Name

The name of the column provided in the [FOCUS dataset](#term).

[ColumnName](#meta) adheres to the following requirements:

* [ColumnName](#meta) MUST be present in an object within the [ColumnDefinition](#meta) collection.
* [ColumnName](#meta) MUST be of type String.
* [ColumnName](#meta) MUST NOT be null.

## Metadata ID

ColumnName

## Metadata Name

Column Name

## Content Constraints

| Constraint      | Value            |
|:----------------|:-----------------|
| Feature level   | Mandatory        |
| Allows nulls    | False            |
| Data type       | String           |
| Value format    | \<not specified> |
