# FOCUS Version

The version of FOCUS utilized for building the dataset.

[FocusVersion](#meta) adheres to the following requirements:

* [FocusVersion](#meta) MUST be present in an object within the [Schema](#meta) collection.
* [FocusVersion](#meta) MUST be of type String.
* [FocusVersion](#meta) MUST NOT be null.
* [FocusVersion](#meta) MUST match one of the published versions of the FOCUS specification.
* [FocusVersion](#meta) MUST match the version of the FOCUS specification that the [dataset instance artifact](#term) conforms to.
