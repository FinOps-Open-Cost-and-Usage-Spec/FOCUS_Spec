# Data Generator

Human-readable name of the entity that generated the dataset instance. The [Data Generator](#meta) ensures the technical accuracy and delivery of the data.

[DataGenerator](#meta) property adheres to the following requirements:

* [DataGenerator](#meta) MUST be present in the [Data Generator](#meta:.DataGenerator) object.
* [DataGenerator](#meta) MUST be of type String.
* [DataGenerator](#meta) MUST conform to [StringHandling](#attr) requirements.
* [DataGenerator](#meta) MUST NOT be null.
* [DataGenerator](#meta) SHOULD reflect the entity that generated the [FOCUS dataset](#term).
