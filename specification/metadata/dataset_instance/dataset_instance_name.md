# Dataset Instance Name

The human-readable name of the dataset instance as provided by the data generator.

The DatasetInstanceName property adheres to the following requirements:

* DatasetInstanceName MUST be present in the [Dataset Instance](#datasetinstance) metadata section.
* DatasetInstanceName MUST be of type String.
* DatasetInstanceName MUST NOT contain null values.

## Metadata ID

DatasetInstanceName

## Metadata Name

Dataset Instance Name

## Content constraints

| Constraint    | Value            |
|:--------------|:-----------------|
| Feature level | Mandatory        |
| Allows nulls  | False            |
| Data type     | String           |
| Value format  | \<not specified> |

## Introduced (version)

1.3
