# Time Sector Complete

[Time Sector Complete](#meta) provides a boolean value to indicate that the time sector is considered complete by the DataGenerator. The definition of complete is determined by the DataGenerator and should be provided in documentation provided by the DataGenerator.

[TimeSectorComplete](#meta) adheres to the following requirements:

* [TimeSectorComplete](#meta) MUST be present in the [TimeSectors](#meta) subsection of the [Recency](#meta) metadata section.
* [TimeSectorComplete](#meta) MUST be of type Boolean.
* [TimeSectorComplete](#meta) MUST not be null.

## Metadata ID

TimeSectorComplete

## Metadata Name

Time Sector Complete
