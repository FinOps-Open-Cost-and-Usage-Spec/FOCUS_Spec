# Dataset ID

The Dataset provides the reference item to associate which Dataset the recency metadata is for.

The DatasetId MUST be present in the metadata. The DatasetId MUST be of String. It is RECOMMENDED for DatasetId to be a Globally Unique Identifier (GUID).

## Metadata ID

DatasetId

## Metadata Name

Dataset ID

## Content constraints

| Constraint    | Value                 |
|:--------------|:----------------------|
| Feature level | Mandatory             |
| Allows nulls  | False                 |
| Data type     | STRING                |
| Value format  | Recommend GUID String |

## Introduced (version)

1.3
