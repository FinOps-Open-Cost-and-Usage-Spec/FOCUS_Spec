# Dataset Instance Last Updated

Datetime when the data present in the Dataset Instance was updated.

[DatasetInstanceLastUpdated](#meta) adheres to the following requirements:

* [DatasetInstanceLastUpdated](#meta) MUST be present in an object within the [Recency](#meta) collection.
* [DatasetInstanceLastUpdated](#meta) MUST be of type Date/Time.
* [DatasetInstanceLastUpdated](#meta) MUST conform to [DateTimeFormat](#attr) requirements.
* [DatasetInstanceLastUpdated](#meta) MUST NOT be null.

## Metadata ID

DatasetInstanceLastUpdated

## Metadata Name

Dataset Instance Last Updated

|:--------------|:-------------------------------------|
| Feature level | Mandatory                            |

| Data type     | Date/Time                            |
