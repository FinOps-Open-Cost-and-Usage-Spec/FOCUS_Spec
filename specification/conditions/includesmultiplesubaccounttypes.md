# Includes Multiple Sub Account Types

The Includes Multiple Sub Account Types condition represents a verifiable state where the [*operating model*](#glossary:operating-model) includes more than one possible SubAccountType value.

## Requirements

IncludesMultipleSubAccountTypes MUST adhere to the following requirements:

* IncludesMultipleSubAccountTypes MUST evaluate to true when the *operating model* includes more than one possible SubAccountType value.
* IncludesMultipleSubAccountTypes MAY evaluate to false when the *operating model* includes only a single SubAccountType value.

## Condition ID

IncludesMultipleSubAccountTypes

## Display Name

Includes Multiple Sub Account Types

## Description

A verifiable state indicating whether the *operating model* includes more than one possible SubAccountType value.

## Version Introduced

1.5
