# Includes Tiered Pricing

The Includes Tiered Pricing condition represents a verifiable state indicating whether the [*operating model*](#glossary:operating-model) includes [*tiered pricing*](#glossary:tiered-pricing).

## Requirements

IncludesTieredPricing MUST adhere to the following requirements:

* IncludesTieredPricing MUST evaluate to true when the *operating model* includes *tiered pricing*.
* IncludesTieredPricing MUST evaluate to false when the *operating model* does not include *tiered pricing*.

## Condition ID

IncludesTieredPricing

## Display Name

Includes Tiered Pricing

## Description

A verifiable state indicating whether the *operating model* includes *tiered pricing*.

## Version Introduced

1.5
