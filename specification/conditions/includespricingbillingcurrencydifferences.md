# Includes Pricing-Billing Currency Differences

The Includes Pricing-Billing Currency Differences condition represents a verifiable state where the [operating model](#glossary:operating-model) includes pricing and billing in different currencies.

## Requirements

IncludesPricingBillingCurrencyDifferences MUST adhere to the following requirements:

* IncludesPricingBillingCurrencyDifferences MUST evaluate to true when the operating model supports pricing in one currency and billing in another.
* IncludesPricingBillingCurrencyDifferences MUST evaluate to false when the operating model strictly uses the same currency for pricing and billing.

## Condition ID

IncludesPricingBillingCurrencyDifferences

## Display Name

Includes Pricing-Billing Currency Differences

## Description

A verifiable state indicating whether the operating model includes pricing and billing in different currencies.

## Version Introduced

1.5
