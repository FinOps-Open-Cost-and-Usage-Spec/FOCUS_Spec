# Includes Negotiated Pricing

The Includes Negotiated Pricing condition represents a verifiable state where the [operating model](#glossary:operating-model) includes negotiated pricing concepts.

## Requirements

IncludesNegotiatedPricing MUST adhere to the following requirements:

* IncludesNegotiatedPricing MUST evaluate to true when the operating model includes negotiated pricing concepts, such as custom rate cards or negotiated discounts.
* IncludesNegotiatedPricing MUST evaluate to false when the operating model operates strictly on standard pricing without the capability for negotiated rates.

## Condition ID

IncludesNegotiatedPricing

## Display Name

Includes Negotiated Pricing

## Description

A verifiable state indicating whether the operating model includes negotiated pricing concepts.

## Version Introduced

1.5
