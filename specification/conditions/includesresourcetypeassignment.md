# Includes Resource Type Assignment

The Includes Resource Type Assignment presence condition represents a verifiable state where the [source operating model](#glossary:source-operating-model) includes assigning types to resources.

## Requirements

IncludesResourceTypeAssignment MUST adhere to the following requirements:

* IncludesResourceTypeAssignment MUST evaluate to true when the source operating model allows categorizing resources by type.
* IncludesResourceTypeAssignment MUST evaluate to false when the source operating model does not support resource typing.

## Presence Condition ID

IncludesResourceTypeAssignment

## Display Name

Includes Resource Type Assignment

## Description

A verifiable state indicating whether the source operating model includes assigning types to resources.

## Version Introduced

1.5
