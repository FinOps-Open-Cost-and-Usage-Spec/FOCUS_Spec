# Includes Resource Type Assignment

The Includes Resource Type Assignment condition represents a verifiable state where the [operating model](#glossary:operating-model) includes assigning types to resources.

## Requirements

IncludesResourceTypeAssignment MUST adhere to the following requirements:

* IncludesResourceTypeAssignment MUST evaluate to true when the operating model allows categorizing resources by type.
* IncludesResourceTypeAssignment MUST evaluate to false when the operating model does not support resource typing.

## Condition ID

IncludesResourceTypeAssignment

## Display Name

Includes Resource Type Assignment

## Description

A verifiable state indicating whether the operating model includes assigning types to resources.

## Version Introduced

1.5
