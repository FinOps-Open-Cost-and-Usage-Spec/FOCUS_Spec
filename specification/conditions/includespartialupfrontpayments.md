# Includes Partial Upfront Payments

The Includes Partial Upfront Payments condition represents a verifiable state indicating whether the [*operating model*](#glossary:operating-model) includes a partial upfront payment model for [*contract commitments*](#glossary:contract-commitment).

## Requirements

IncludesPartialUpfrontPayments MUST adhere to the following requirements:

* IncludesPartialUpfrontPayments MUST evaluate to true when the *operating model* offers a "Partial Upfront" payment model for commitments.
* IncludesPartialUpfrontPayments MUST evaluate to false when the *operating model* strictly uses "All Upfront" or "No Upfront" payment models.

## Condition ID

IncludesPartialUpfrontPayments

## Display Name

Includes Partial Upfront Payments

## Description

A verifiable state indicating whether the *operating model* includes a partial upfront payment model for contract commitments.

## Version Introduced

1.5
