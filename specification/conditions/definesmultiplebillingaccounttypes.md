# Defines Multiple Billing Account Types

The Defines Multiple Billing Account Types presence condition represents a verifiable state where the [source operating model](#glossary:source-operating-model) defines more than one possible BillingAccountType value.

## Requirements

DefinesMultipleBillingAccountTypes MUST adhere to the following requirements:

* DefinesMultipleBillingAccountTypes MUST evaluate to true when the source operating model defines more than one possible BillingAccountType value.
* DefinesMultipleBillingAccountTypes MUST evaluate to false when the source operating model defines only a single BillingAccountType value.

## Presence Condition ID

DefinesMultipleBillingAccountTypes

## Display Name

Defines Multiple Billing Account Types

## Description

A verifiable state indicating whether the source operating model defines more than one possible BillingAccountType value.

## Version Introduced

1.5
