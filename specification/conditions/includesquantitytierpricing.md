# Includes Quantity Tier Pricing

The Includes Quantity Tier Pricing condition represents a verifiable state indicating whether the [*operating model*](#glossary:operating-model) includes quantity-based pricing tiers.

## Requirements

IncludesQuantityTierPricing MUST adhere to the following requirements:

* IncludesQuantityTierPricing MUST evaluate to true when the *operating model* includes quantity-based pricing tiers.
* IncludesQuantityTierPricing MUST evaluate to false when the *operating model* does not include quantity-based pricing tiers.

## Condition ID

IncludesQuantityTierPricing

## Display Name

Includes Quantity Tier Pricing

## Description

A verifiable state indicating whether the *operating model* includes quantity-based pricing tiers.

## Version Introduced

1.5
