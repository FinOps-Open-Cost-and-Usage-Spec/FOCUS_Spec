# Includes Billing Account Naming

The Includes Billing Account Naming condition represents a verifiable state where the [operating model](#glossary:operating-model) includes assigning a display name for the billing account.

## Requirements

IncludesBillingAccountNaming MUST adhere to the following requirements:

* IncludesBillingAccountNaming MUST evaluate to true when the operating model allows assigning a display name for the billing account.
* IncludesBillingAccountNaming MUST evaluate to false when the operating model does not allow assigning a display name for the billing account.

## Condition ID

IncludesBillingAccountNaming

## Display Name

Includes Billing Account Naming

## Description

A verifiable state indicating whether the operating model includes assigning a display name for the billing account.

## Version Introduced

1.5
