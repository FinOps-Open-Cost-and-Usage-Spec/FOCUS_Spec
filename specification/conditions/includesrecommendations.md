# Includes Recommendations

The Includes Recommendations condition represents a verifiable state indicating whether the [*operating model*](#glossary:operating-model) includes recommendations for [*resources*](#glossary:resource) or [*services*](#glossary:service).

## Requirements

IncludesRecommendations MUST adhere to the following requirements:

* IncludesRecommendations MUST evaluate to true when the *operating model* includes recommendations for *resources* or *services*.
* IncludesRecommendations MUST evaluate to false when the *operating model* does not include recommendations for *resources* or *services*.

## Condition ID

IncludesRecommendations

## Display Name

Includes Recommendations

## Description

A verifiable state indicating whether the *operating model* includes recommendations for resources or services.

## Version Introduced

1.5
