# Defines Multiple Sub Account Types

The Defines Multiple Sub Account Types condition represents a verifiable state where the [operating model](#glossary:operating-model) defines more than one possible SubAccountType value.

## Requirements

DefinesMultipleSubAccountTypes MUST adhere to the following requirements:

* DefinesMultipleSubAccountTypes MUST evaluate to true when the operating model defines more than one possible SubAccountType value.
* DefinesMultipleSubAccountTypes MUST evaluate to false when the operating model defines only a single SubAccountType value.

## Condition ID

DefinesMultipleSubAccountTypes

## Display Name

Defines Multiple Sub Account Types

## Description

A verifiable state indicating whether the operating model defines more than one possible SubAccountType value.

## Version Introduced

1.5
