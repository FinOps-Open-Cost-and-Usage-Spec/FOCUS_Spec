# Includes Tags

The Includes Tags condition represents a verifiable state indicating whether the [*operating model*](#glossary:operating-model) includes the definition or enrichment of tags.

## Requirements

IncludesTags MUST adhere to the following requirements:

* IncludesTags MUST evaluate to true when the *operating model* supports setting user or provider-defined tags.
* IncludesTags MUST evaluate to false when the *operating model* does not support setting user or provider-defined tags.

## Condition ID

IncludesTags

## Display Name

Includes Tags

## Description

A verifiable state indicating whether the *operating model* includes the definition or enrichment of tags.

## Version Introduced

1.5
