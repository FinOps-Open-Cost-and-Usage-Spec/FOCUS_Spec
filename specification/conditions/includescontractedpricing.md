# Includes Contracted Pricing

The Includes Contracted Pricing presence condition represents a verifiable state where the source operating model supports formal commercial agreements, custom rate cards, or overarching spend commitments.

## Requirements

IncludesContractedPricing MUST adhere to the following requirements:

* IncludesContractedPricing MUST evaluate to true when the source operating model includes mechanisms for customized rates, negotiated discounts, or overarching spend commitments (e.g., Enterprise Agreements).
* IncludesContractedPricing MUST evaluate to false when the source operating model operates strictly on a standard, pay-as-you-go basis without the capability for custom commercial agreements or negotiated rate overrides.

## Presence Condition ID

IncludesContractedPricing

## Display Name

Includes Contracted Pricing

## Description

A verifiable state indicating whether the source operating model includes formal contracts, spend commitments, or negotiated pricing.

1.5
