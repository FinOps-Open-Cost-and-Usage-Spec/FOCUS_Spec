# Includes Principals

The Includes Principals condition represents a verifiable state indicating whether the [*operating model*](#glossary:operating-model) includes [*charges*](#glossary:charge) associated with a [*principal*](#glossary:principal).

## Requirements

IncludesPrincipals MUST adhere to the following requirements:

* IncludesPrincipals MUST evaluate to true when the *operating model* includes *charges* associated with a *principal*.
* IncludesPrincipals MUST evaluate to false when the *operating model* does not include *charges* associated with a *principal*.

## Condition ID

IncludesPrincipals

## Display Name

Includes Principals

## Description

A verifiable state indicating whether the *operating model* includes *charges* associated with a *principal*.

## Version Introduced

1.5
