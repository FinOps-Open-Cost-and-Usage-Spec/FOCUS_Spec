# Includes Principals

The Includes Principals condition represents a verifiable state indicating whether the [*operating model*](#glossary:operating-model) includes [*principals*](#glossary:principal).

## Requirements

IncludesPrincipals MUST adhere to the following requirements:

* IncludesPrincipals MUST evaluate to true when the *operating model* includes *principals*.
* IncludesPrincipals MUST evaluate to false when the *operating model* does not include *principals*.

## Condition ID

IncludesPrincipals

## Display Name

Includes Principals

## Description

A verifiable state indicating whether the *operating model* includes *principals*.

1.5
