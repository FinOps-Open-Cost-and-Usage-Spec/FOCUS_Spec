# Includes Multiple Services

The Includes Multiple Services condition represents a verifiable state where the [operating model](#glossary:operating-model) includes multiple services.

## Requirements

IncludesMultipleServices MUST adhere to the following requirements:

* IncludesMultipleServices MUST evaluate to true when the operating model provides multiple distinct services.
* IncludesMultipleServices MUST evaluate to false when the operating model provides only a single service.

## Condition ID

IncludesMultipleServices

## Display Name

Includes Multiple Services

## Description

A verifiable state indicating whether the operating model includes multiple services.

## Version Introduced

1.5
