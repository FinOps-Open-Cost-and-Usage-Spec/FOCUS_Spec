# Includes Consumers

The Includes Consumers condition represents a verifiable state indicating whether the [*operating model*](#glossary:operating-model) includes [*consumers*](#glossary:consumer).

## Requirements

IncludesConsumers MUST adhere to the following requirements:

* IncludesConsumers MUST evaluate to true when the *operating model* includes *consumers*.
* IncludesConsumers MUST evaluate to false when the *operating model* does not include *consumers*.

## Condition ID

IncludesConsumers

## Display Name

Includes Consumers

## Description

A verifiable state indicating whether the *operating model* includes *consumers*.

## Version Introduced

1.5
