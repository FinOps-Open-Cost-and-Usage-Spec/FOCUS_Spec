# Includes Consumers

The Includes Consumers condition represents a verifiable state indicating whether the [*operating model*](#glossary:operating-model) includes [*charges*](#glossary:charge) attributed to a [*consumer*](#glossary:consumer).

## Requirements

IncludesConsumers MUST adhere to the following requirements:

* IncludesConsumers MUST evaluate to true when the *operating model* includes *charges* attributed to a *consumer*.
* IncludesConsumers MUST evaluate to false when the *operating model* does not include *charges* attributed to a *consumer*.

## Condition ID

IncludesConsumers

## Display Name

Includes Consumers

## Description

A verifiable state indicating whether the *operating model* includes *charges* attributed to a *consumer*.

1.5
