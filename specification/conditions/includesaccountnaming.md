# Includes Account Naming

The Includes Account Naming condition represents a verifiable state where the [operating model](#glossary:operating-model) includes assigning a display name for the billing account.

## Requirements

IncludesAccountNaming MUST adhere to the following requirements:

* IncludesAccountNaming MUST evaluate to true when the operating model allows assigning a display name for the billing account.
* IncludesAccountNaming MUST evaluate to false when the operating model does not allow assigning a display name for the billing account.

## Condition ID

IncludesAccountNaming

## Display Name

Includes Account Naming

## Description

A verifiable state indicating whether the operating model includes assigning a display name for the billing account.

## Version Introduced

1.5
