# Includes Provisioned Resources

The Includes Provisioned Resources condition represents a verifiable state where the [*operating model*](#glossary:operating-model) includes provisioned resources.

## Requirements

IncludesProvisionedResources MUST adhere to the following requirements:

* IncludesProvisionedResources MUST evaluate to true when the *operating model* identifies and tracks individual provisioned resources.
* IncludesProvisionedResources MUST evaluate to false when the *operating model* does not track individual provisioned resources.

## Condition ID

IncludesProvisionedResources

## Display Name

Includes Provisioned Resources

## Description

A verifiable state indicating whether the *operating model* includes provisioned resources.

## Version Introduced

1.5
