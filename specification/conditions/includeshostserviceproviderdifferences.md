# Includes Host-Service Provider Differences

The Includes Host-Service Provider Differences condition represents a verifiable state where the [operating model](#glossary:operating-model) includes public delineation between host and service provider.

## Requirements

IncludesHostServiceProviderDifferences MUST adhere to the following requirements:

* IncludesHostServiceProviderDifferences MUST evaluate to true when the operating model explicitly delineates between the host provider and the service provider.
* IncludesHostServiceProviderDifferences MUST evaluate to false when the operating model does not distinguish between host and service provider.

## Condition ID

IncludesHostServiceProviderDifferences

## Display Name

Includes Host-Service Provider Differences

## Description

A verifiable state indicating whether the operating model includes public delineation between host and service provider.

## Version Introduced

1.5
