# [FR] Define policy of AI usage in FOCUS project

**Issue:** #1805
**Labels:** needs triage, feature
**Type:** Supporting Content (e.g., appendices, use cases)

## Problem Statement

We all increasingly use AI as a tool for our day-to-day efforts. It is now possible in GitHub to use the Copilot AI to perform various repo tasks like authoring commits and reviewing PRs.

Such actions -- particularly commits -- are not yet allowed in the FOCUS repository. For example, PR #1801 was co-authored by Copilot, but it is not allowed because `copilot-swe-agent` is not covered under EasyCLA. This could be changed, but we need to establish and agree on a policy of AI usage in the FOCUS project.

## Desired Outcome / Practitioner Impact

A clear policy for AI usage in the FOCUS project, drafted and agreed to by the working group members.

## Level of Ambiguity

3 (moderate)

## Notes

- This is a governance/policy issue, not a specification change
- Requires working group consensus
- Related to EasyCLA and contributor agreements
